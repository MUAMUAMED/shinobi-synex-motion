## Regras que saem daqui
- O fim de quase toda cena é uma forma simples que vira a próxima.
- Interface nunca fica parada: tem clique, contador ou digitação.
- Painéis diagonais empilham, cada um revelando um benefício.
- A mão é grande, com contorno e sombra, de propósito.
